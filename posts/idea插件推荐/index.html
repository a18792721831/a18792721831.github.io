Alibaba Java Coding Guidelines

阿里巴巴编码规范，实时检测。

Backgroud Image Plus +

idea背景图

Codota AI Autocomplete for Java and JavaScript

重磅推荐：提供一些推荐的变量名，常用的模板方法等。






GenerateAllSetter

重磅推荐：一键生成一个对象的全部set方法，可以选择无默认值或者根据类型的默认值。


Grep Console

控制台输出日志自定义颜色。

Java Bean to Json

将对象转为json

jclasslib Bytecode Viewer

字节码查看器，在查看代码的时候，如果依赖的第三方包没有下载源码，使用这个插件可以直接查看字节码。

Mybatis Log

mybatis打印日志的配置。
在控制台打印的mybatis的日志，一般是sql和参数分离的。使用这个插件可以将参数合并到sql中。

MyBatisCodeHelperPro

mybatis开发插件，可以直接调试xml,同时提供接口和xml的链接。
需付费，可以使用邮箱免费试用7天.

POJO Generator

生成符合jpa规范的PO类。对于日期类型和枚举类型不友好，需要额外处理。

Rainbow Brackets

彩虹符号，将成对的括弧，中括弧，大括弧进行颜色配对。

RestfulToolkit

restful接口工具，提供restful的报文请求。

SequenceDiagram

重磅推荐：生成时序图。根据代码生成时序图。

Stack trace to UML

根据异常堆栈，生成UML关系图。
