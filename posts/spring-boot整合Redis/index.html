1. Redis简介

Redis 是一个开源的、先进的 key-value 存储系统，可用于构建高性能的存储系统。Redis
支持数据结构有字符串、哈希、列表、集合、排序集合、位图、超文本等。NoSQL（Not Only SQL）泛指非关系型的数据库。Redis 是一种NoSQL，Redis 具有很多的优点，例如读写非常快速，支持丰富的数据类型，所有的操作都是原子的。
