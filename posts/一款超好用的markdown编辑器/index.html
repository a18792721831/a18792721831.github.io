1. Typora

1.1 Typora介绍

Typora 是一款支持实时预览的 Markdown 文本编辑器 。它有 OS X、Windows、Linux 三个平台的版本，并且由于仍在测试中，是完全免费 的。

1.2 为什么推荐Typora

简洁：没有什么无用的功能，所有的功能都可以通过快捷方式实现。

插图方便：插图非常方便，特别是截图后，直接粘贴即可(此时存储在了临时文件中，可以和其他软件配合，实现上传到图床)

代码：程序员的文章，怎么都离不开代码，但是在markdown中，代码展示的好看与否，是评价一款markdown编辑器是否好用的一个因素。

两种模式：专注模式和打字机模式。专注模式，编辑的行突出显示。打字机模式，编辑的行处于最中间。

实时预览：就像编写word文档一样，写完之后，就会渲染markdown，隐藏markdown的标记。

emoji提示：使用:emoji就能输入表情，同时还有提示(在使用的过程中有大量的提示)

强大的导出：markdown是以.md保存的，但是如果他人没有markdown浏览器的话，就只能看到源码。这就涉及到markdown转其他格式，比如pdf,html等。Ttypora支持文件导出，支持10多种目标格式。

开放的主题：Ttypora自带了5中主题，不过可以从Typora主题市场下载更多的主题。你如果懂css语法，你可以自己定义。

最后：使用Typora有更好的效率，不用左右两栏跳转，写完的就是最终展示的。

2. PicGo
