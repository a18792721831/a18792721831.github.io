## 1\. 命令行

写命令行程序时需要对命令参数进行解析，这时可以使用标准库的 os 包。 os 包可以通过变量 Args 来获取命令参数， os.Args 返回一个字符串数组，其中第一个参数就是执行文件本身。

假设有如下源码：
    
    
    package main
    
    import (
    	"fmt"
    	"os"
    )
    
    func main() {
       
       
    	fmt.Println(os.Args)
    	for k, v := range os.Args {
       
       
    		fmt.Println(k, v)
    	}
    }

## 2\. 参数解析

Flag 包是Go语言标准库提供的用来解析命令行参数的包，使得开发命令行工具更为简单。

flag 包支持的标志格式有：

  * -flag : 代表 bool 值，相当于 -flag=true
  * -flag=x : 支持任意值
  * -flag x: 不支持 bool 值标志

一个简单的小例子
    
    
    package main
    
    import (
    	"flag"
    	"fmt"
    )
    
    var (
    	h, H bool
    	v    bool
    	q    *bool
    	D    string
    	Conf string
    )
    
    func init() {
       
       
    	flag.BoolVar(&h, "h", false, "帮助信息")
    	flag.BoolVar(&H, "H", false, "帮助信息")
    
    	flag.BoolVar(&v, "v", false, "显示版本信息")
    
    	flag.StringVar(&D, "D", "deamon", "设置为deamon模式")
    	flag.StringVar(&Conf, "conf", "./conf/captain.conf", "配置文件")
    
    	q = flag.Bool("q", false, "quiet")
    
    	flag.Usage = func() {
       
       
    		fmt.Println("Usage: captain [options]")
    
    		flag.PrintDefaults()
    	}
    	flag.Parse()
    
    	cmd := flag.Arg(0)
    	fmt.Println(cmd)
    	fmt.Println(flag.Args())
    	fmt.Printf("q: %v\n", *q)
    	fmt.Printf("h: %v\n", h)
    	fmt.Printf("deamon: %s", D)
    	fmt.Printf("conf: %s", Conf)
    	fmt.Println(flag.NArg())
    
    }
    
    func main() {
       
       
    	//fmt.Println(os.Args)
    	//for k, v := range os.Args {
       
       
    	//	fmt.Println(k, v)
    	//}
    
    	flag.Parse()
    	if h || H {
       
       
    		flag.Usage()
    		return
    	}
    }

### 2.1 flag 参数定义绑定

定义flag 有两种方式：

  * Flag.Xxx() : 其中 Xxx 可以是 Int, String 等，返回一个相应类型的指针：

`q = flag.Bool("q", false, "quiet")`

  * Flag.XxxVar(): 将flag绑定到一个变量上：

`flag.StringVar(&Conf, "conf", "./conf/captain.conf", "配置文件")`

  * 自定义flag，需要实现 flag.Value 接口
