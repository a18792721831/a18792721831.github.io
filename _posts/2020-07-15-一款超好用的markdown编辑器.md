## 1\. Typora

### 1.1 Typora介绍

Typora 是一款**支持实时预览的 Markdown 文本编辑器** 。它有 OS X、Windows、Linux 三个平台的版本，并且由于仍在测试中，是**完全免费** 的。

### 1.2 为什么推荐Typora

简洁：没有什么无用的功能，所有的功能都可以通过快捷方式实现。

插图方便：插图非常方便，特别是截图后，直接粘贴即可(此时存储在了临时文件中，可以和其他软件配合，实现上传到图床)

代码：程序员的文章，怎么都离不开代码，但是在markdown中，代码展示的好看与否，是评价一款markdown编辑器是否好用的一个因素。
    
    
    public void main(String[] args){
        // ss
        /* sasda */
        System.out.println("asdasda");
    }
    

时序图
    
    
    Note left of A : mm
    A -> B : hello
    B -> B : sss 10
    B -> C : hh
    Note right of C : dd
    C -> C : sss
    C -> B : retturn
    B -> A : return
    

A  B  C  mm  hello  sss 10  hh  dd  sss  retturn  return  A  B  C 

流程图
    
    
    st=>start: 开始
    op1=>operation: 第一步
    op2=>operation: 第二部
    c1=>condition: 开始?
    e=>end: 结束
    
    st->op1->op2->c1
    c1(yes)->e
    c1(no)->op1
    

Created with Raphaël 2.2.0  开始  第一步  第二部  开始?  结束  yes  no 

两种模式：专注模式和打字机模式。专注模式，编辑的行突出显示。打字机模式，编辑的行处于最中间。

实时预览：就像编写word文档一样，写完之后，就会渲染markdown，隐藏markdown的标记。

emoji提示：使用`:emoji`就能输入表情，同时还有提示(在使用的过程中有大量的提示)

🐶👨👩🤗🌈

表格可视化：普通的markdown一般是使用
    
    
    |1|2|3|
    |:-:|:-:|:-:|
    |1|2|3|
    

而Typora是使用可视化的(使用`ctrl+T`)

|     |    |    |
|-----|----|----|
|     |    |    |
|     |    |    |
|     |    |    |

![image-20200715172851735](https://picgo-1302191088.cos.ap-guangzhou.myqcloud.com/csdn/csdnimg/dbdd5fb3eda04f0d79285cf38b298827.png)

脚注：使用`[^ n ]`添加引用，使用`[^ n ]: xxx`生成脚注

test[^ 1 ](<%E5%93%88%E5%93%88%E5%93%88>)

强大的导出：markdown是以`.md`保存的，但是如果他人没有markdown浏览器的话，就只能看到源码。这就涉及到markdown转其他格式，比如pdf,html等。Ttypora支持文件导出，支持10多种目标格式。

开放的主题：Ttypora自带了5中主题，不过可以从[Typora主题市场](<http://theme.typora.io/>)下载更多的主题。你如果懂css语法，你可以自己定义。

最后：使用Typora有更好的效率，不用左右两栏跳转，写完的就是最终展示的。

## 2\. PicGo

所谓图床工具，就是自动把本地图片转换成链接的一款工具，网络上有很多图床工具，就目前使用种类而言，PicGo 算得上一款比较优秀的图床工具。它是一款用 `Electron-vue` 开发的软件，可以支持微博，七牛云，腾讯云COS，又拍云，GitHub，阿里云OSS，SM.MS，imgur 等8种常用图床，功能强大，简单易用.
