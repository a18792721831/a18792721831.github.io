在 go 语言中注释有两种，行注释和块注释

## 行注释

使用双斜线 `//` 开始，一般后面紧跟一个空格。行注释是Go语言中最常见的注释形式，在标准包中，一般都采用行注释，即使需要多行也尽量使用行注释。

![在这里插入图片描述](https://picgo-1302191088.cos.ap-guangzhou.myqcloud.com/csdn/csdnimg/bd55ca1daae49f9ec771ca8c9f9adaf1.png)

## 块注释

以 `/*` 开头，以 `*/` 结尾，不能嵌套使用。块注释一般用于包描述或注释成块的代码片段。

![在这里插入图片描述](https://picgo-1302191088.cos.ap-guangzhou.myqcloud.com/csdn/csdnimg/5ed2775728176570171eb2e29ffb4e1f.png)

## 文档

注释不仅仅在写代码时，在IDE进行展示，帮助开发人员更好的选择使用哪个调用，还能输出文档。

使用 `go doc <package>` 可以查看包的文档

![在这里插入图片描述](https://picgo-1302191088.cos.ap-guangzhou.myqcloud.com/csdn/csdnimg/f6fdeb78202ea856725ef17ca4d68e06.png)

使用 `go doc <package.struct>` 可以查看包下具体的文档

![在这里插入图片描述](https://picgo-1302191088.cos.ap-guangzhou.myqcloud.com/csdn/csdnimg/5f5a9c6d62a546d8b9a0b9d8604c06e4.png)

使用`go doc <package.struct.method>` 可以查看具体的方法或者函数的文档

![在这里插入图片描述](https://picgo-1302191088.cos.ap-guangzhou.myqcloud.com/csdn/csdnimg/591a6104303b8a6b21b7f6b2496e5b03.png)

除此之外，还可以使用 `godoc -http :9393` 查看HTML格式的文档

> godoc 并不会自动安装，如果命令不识别，需要安装 mac : `brew install godoc`
> 
> godoc 在 1.20 版本被移出标准组件，使用 `go install golang.org/x/tools/cmd/godoc@latest` 安装

使用 `godoc -http :9393` 后，会自动在命令执行目录下寻找 go.mod ，然后加载 go.mod
