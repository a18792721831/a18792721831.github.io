## [r56(2011/03/16)](<https://golang.google.cn/doc/devel/pre_go1#r56>)

r56 版本是第一个稳定版本，对应于 `weekly.2011-03-07.1`。编号从 56 开始，因为在此版本之前，我们现在认为的每周快照被称为版本。

对应的周会记录：

https://golang.google.cn/doc/devel/weekly#2011-03-07

周会记录原文：
    
    
    This release includes changes to the reflect and path packages.
    Code that uses reflect or path may need to be updated.
    
    The reflect package's Value.Addr method has been renamed to Value.UnsafeAddr.
    Code that uses the Addr method will have to call UnsafeAddr instead.
    
    The path package has been split into two packages: path and path/filepath.
    Package path manipulates slash-separated paths, regardless of operating system.
    Package filepath implements the local operating system's native file paths.
    OS-specific functionality in package path, such as Walk, moved to filepath.
    
    Other changes:
    * build: fixes and simplifications (thanks Dave Cheney),
            move $GOBIN ahead of /bin, /usr/bin in build $PATH.
    * bzip2: speed up decompression.
    * cgo: fix dwarf type parsing (thanks Gustavo Niemeyer),
            put temporary source files in _obj (thanks Roger Peppe),
            fix bug involving 0-argument callbacks.
    * compress/lzw: optimizations.
    * doc: add FAQ about "implements",
            add FAQ about large binaries ,
            add FAQ about stack vs heap allocation,
            add internationalization to roadmap,
            describe platform-specific conventions in code.html.
    * fmt: allow recursive calls to Fscan etc (thanks Roger Peppe),
            make %#p suppress leading 0x.
    * gc, gopack: add some missing flags to the docs.
    * gc: fix init of packages named main (thanks Gustavo Niemeyer),
    * gob: make recursive map and slice types work, and other fixes.
            tentative support for GobEncoder/GobDecoder interfaces.
    * gobuilder: add -package flag to build external packages and -v for verbose.
    * gofmt: exclude test file that is not legal Go.
    * goinstall: protect against malicious filenames (thanks Roger Peppe).
    * goyacc: provide -p flag to set prefix for names, documentation update.
    * http: add cookie support (thanks Petar Maymounkov),
            allow handlers to send non-chunked responses,
            export ParseHTTPVersion,
            expose Client's Transport,
            use WriteProxy,
            rename ClientTransport to Transport.
    * http/cgi: new package.
    * http/httptest: new package.
    * image: add a decoding test for common file formats.
    * io/ioutil: add TempDir.
    * mime/multipart: Header changed from map to MIMEHeader
    * path/filepath: new OS-specific path support (thanks Gustavo Niemeyer).
    * reflect: add PtrTo, add Value.Addr (old Addr is now UnsafeAddr).
    * runtime: use kernel-supplied compare-and-swap on linux/arm.
    * spec: minor clarification of scope rule for functions.
    * sync/atomic: new package to expose atomic operations.
    * syscall: regenerate zerrors_freebsd_amd64.go (thanks Mikio Hara),
            work around FreeBSD execve kernel bug (thanks Devon H. O'Dell).
    * template: document the delimiters.
    * testing: run GC before each benchmark run (thanks Roger Peppe).
    * unsafe: fix the documentation.
    * websocket: use httptest.Server for tests (thanks Robert Hencke).
    * xml: permit nested directives (thanks Chris Dollin).
    

简单总结一下：

**主要更改概述**

  1. **reflect 包** :

     * `Value.Addr` 方法重命名为 `Value.UnsafeAddr`。
  2. **path 包** :

     * 拆分为两个包：`path`（处理斜杠分隔路径）和 `path/filepath`（处理本地操作系统的文件路径）。
     * OS-specific 功能（如 Walk）已移至 `filepath`。

* * *

**其他重要更改**

  * **构建系统** : 修复和简化，调整 `$GOBIN` 的位置。
  * **性能优化** : 
    * bzip2 解压缩速度提升。
    * compress/lzw 优化。
  * **文档更新** : 添加多个常见问题解答，更新代码文档。
  * **HTTP 包** : 
    * 新增 cookie 支持。
    * 允许非分块响应。
    * 重命名 ClientTransport。
  * **新包** : 新增 `http/cgi` 和 `http/httptest` 包。
  * **其他改进** : 
    * `io/ioutil` 添加 `TempDir`。
    * `mime/multipart` 的 Header 类型更改。
    * `sync/atomic` 新增原子操作包。
    * `testing` 在基准测试前运行 GC。

* * *

**其他修复和改进**

  * 修复了多个包中的错误和文档问题，增强了安全性和功能性。

## [r57(2011/05/03)](<https://golang.google.cn/doc/devel/pre_go1#r57>)

r57 版本 `weekly.2011-04-27` 与附加错误修复相对应。

### Gofix 工具

新的[gofix](<https://golang.google.cn/cmd/gofix>)工具会查找使用旧 API 的 Go 程序，并重写它们以使用较新的 API。在您更新到新的 Go 版本后，gofix 会帮助对您的程序进行必要的更改。Gofix 将处理下面描述的 http、os 和 syscall 包更改，我们将更新程序以跟上库的未来更改。Gofix 无法完美处理所有情况，因此请在提交更改之前阅读并测试它所做的更改。有关更多信息，请参阅[gofix 博客文章。](<https://golang.google.cn/blog/introducing-gofix>)

> 这应该是为了处理兼容的一个升级工具。

### [语言](<https://golang.google.cn/doc/devel/pre_go1#r57.lang>)

[多重赋值语法](<https://golang.google.cn/doc/go_spec.html#Receive_operator>)取代了`closed`函数。通道接收的语法允许可选的第二个赋值，即一个布尔值，表示通道是否关闭。此代码：
    
    
    	v := <-ch 
    	if closed(ch) { 
    		// 通道已关闭
    	}
    

现在应该写成：
    
    
    	v, ok := <-ch 
    	if !ok { 
    		// 通道已关闭
    	}
    

[未使用的标签现在是非法的](<https://golang.google.cn/doc/go_spec.html#Label_scopes>)，就像未使用的局部变量一样。

### [包](<https://golang.google.cn/doc/devel/pre_go1#r57.pkg>)

[gob 包现在将对实现](<https://golang.google.cn/pkg/gob/>)[GobEncoder](<https://golang.google.cn/pkg/gob/#GobEncoder>)和 [GobDecoder](<https://golang.google.cn/pkg/gob/#GobDecoder>)接口的类型的值进行编码和解码 。这允许具有未导出字段的类型传输自洽描述；示例包括 [big.Int](<https://golang.google.cn/pkg/big/#Int.GobDecode>)和[big.Rat](<https://golang.google.cn/pkg/big/#Rat.GobDecode>)。

[http 包](<https://golang.google.cn/pkg/http/>)已经重新设计。对于客户端，有了新的 [Client](<https://golang.google.cn/pkg/http/#Client>)和[Transport](<https://golang.google.cn/pkg/http/#Transport>) 抽象，可以更好地控制 HTTP 细节，例如发送的标头和随后的重定向。这些抽象可以轻松实现添加功能（例如[OAuth2 ）](<https://code.google.com/p/goauth2/source/browse/oauth/oauth.go>)的自定义客户端。对于服务器，[ResponseWriter](<https://golang.google.cn/pkg/http/#ResponseWriter>) 已删除其非必要方法。Hijack 和 Flush 方法不再是需要的；代码可以通过检查特定值是否实现 [Hijacker](<https://golang.google.cn/pkg/http/#Hijacker>)或[Flusher](<https://golang.google.cn/pkg/http/#Flusher>)来测试它们。RemoteAddr 和 UsingTLS 方法被[Request](<https://golang.google.cn/pkg/http/#Request>)的 RemoteAddr 和 TLS 字段取代。SetHeader 方法被 Header 方法取代；其结果为[Header](<https://golang.google.cn/pkg/http/#Header>)类型，实现了 Set 和其他方法。

[net 包](<https://golang.google.cn/pkg/net/>) 删除了[Dial](<https://golang.google.cn/pkg/net/#Conn.Dial>)`laddr`中的参数 和[LookupHost](<https://golang.google.cn/pkg/net/#LookupHost>)中的返回值。现在，实现使用[cgo](<https://golang.google.cn/cmd/cgo/>)来实现网络名称查找，如果可能的话，使用 C 库 getaddrinfo(3) 函数。这确保了 Go 和 C 程序以相同的方式解析名称，同时还避开了 OS X 应用程序级防火墙。 `cname`

[os 软件包](<https://golang.google.cn/pkg/os/>) 引入了简化的[Open](<https://golang.google.cn/pkg/os/#File.Open>) 和[Create](<https://golang.google.cn/pkg/os/#File.Create>)函数。原来的 Open 函数现在可用作[OpenFile 函数。StartProcess](<https://golang.google.cn/pkg/os/#File.OpenFile>)[函数](<https://golang.google.cn/pkg/os/#Process.StartProcess>)的最后三个参数已被指向[ProcAttr 的](<https://golang.google.cn/pkg/os/#ProcAttr>) 指针所取代。

重新设计了 [reflect 包](<https://golang.google.cn/pkg/reflect/>)。Type现在是一个实现所有可能的类型方法的接口。类型开关不再是 Type ，而是 switch on 。Value 现在是一个实现所有可能的值方法的结构体[值](<https://golang.google.cn/pkg/reflect/#Value>)。类型开关不再是 Value ，而是[switch](<https://golang.google.cn/pkg/reflect/#Type>) on 。Typeof 和 NewValue 现在被称为[TypeOf](<https://golang.google.cn/pkg/reflect/#Type.TypeOf>)和[ValueOf](<https://golang.google.cn/pkg/reflect/#Value.ValueOf>) 。 要创建可写的 Value ，请使用而不是。有关完整详情，请参阅[变更说明](<https://golang.google.cn/change/843855f3c026>) 。新 API 允许更有效地实现 Value ，从而避免了以前 API 所需的许多分配。 `t``t.Kind()``v``v.Kind()``New(t).Elem()``Zero(t)`

请记住，gofix 将处理这些包 API 更改所需的大部分重写。

### [工具](<https://golang.google.cn/doc/devel/pre_go1#r57.cmd>)

上面介绍了一个新的命令[Gofix 。](<https://golang.google.cn/cmd/gofix/>)

[Gotest](<https://golang.google.cn/cmd/gotest/>)现在是一个 Go 程序，而不是 shell 脚本。新`-test.short`标志与包测试的 Short 函数相结合，允许您编写可以在正常或“短”模式下运行的测试；all.bash 以短模式运行测试以减少安装时间。Makefile 知道该标志：使用`make testshort`。

> 这可能就是 go test 的雏形

运行时支持现在实现了 CPU 和内存分析。Gotest 的新 [`-test.cpuprofile`和 `-test.memprofile`标志](<https://golang.google.cn/cmd/gotest/>)使分析测试变得容易。要将分析添加到您的 Web 服务器，请参阅[http/pprof](<https://golang.google.cn/pkg/http/pprof/>) 文档。有关其他用途，请参阅[运行时/pprof](<https://golang.google.cn/pkg/runtime/pprof/>)文档。

## [r59(2011/08/01)](<https://golang.google.cn/doc/devel/pre_go1#r59>)

r59 版本对应于 `weekly.2011-07-07`。

### [语言](<https://golang.google.cn/doc/devel/pre_go1#r59.lang>)

此版本包含一项语言更改，限制了 的使用 `goto`。本质上，`goto`块外的语句不能跳转到该块内的标签。如果您的代码使用 ，则可能需要进行更改`goto`。请参阅[此变更集](<https://golang.google.cn/change/dc6d3cf9279d>)，了解新规则如何影响 Go 树。

### [包](<https://golang.google.cn/doc/devel/pre_go1#r59.pkg>)

与往常一样，[gofix](<https://golang.google.cn/cmd/gofix/>)将处理这些包 API 更改所需的大部分重写。

[软件包 http](<https://golang.google.cn/pkg/http>)有一个新的 [FileSystem](<https://golang.google.cn/pkg/http/#FileSystem>)接口，可用于访问文件。FileServer助手现在接受 参数[，](<https://golang.google.cn/pkg/http/#FileServer>)`FileSystem`而不是显式文件系统根目录。通过实现您自己的功能，`FileSystem`您可以使用它 `FileServer`来提供任意数据。

[软件包 os](<https://golang.google.cn/pkg/os/>)的`ErrorString`类型已被隐藏。 的大部分用法都可以用[os.NewError](<https://golang.google.cn/pkg/os/#NewError>)`os.ErrorString`代替 。

[reflect 包](<https://golang.google.cn/pkg/reflect/>)支持一种新的结构标签方案，允许在多个包之间共享结构标签。在此方案中，标签必须采用以下格式：
    
    
    `key:"value" key2:"value2"`
    

StructField类型的 Tag 字段现在具有[StructTag](<https://golang.google.cn/pkg/reflect/#StructTag>)类型，它具有一个 方法。json 和 xml 的客户端[需要](<https://golang.google.cn/pkg/reflect/#StructField>)更新 [。](<https://golang.google.cn/pkg/xml>)代码 [如下](<https://golang.google.cn/pkg/json>)`Get`
    
    
    type T struct {
    		X int "name"
    }
    

应该成为
    
    
    type T struct {
    		X int `json:"name"`  // or `xml:"name"`
    }
    

使用[govet](<https://golang.google.cn/cmd/govet/>)来识别需要更改以使用新语法的结构标签。

> go vet 的雏形

[包 sort](<https://golang.google.cn/pkg/sort/>)的`IntArray`类型已重命名为[IntSlice ， ](<https://golang.google.cn/pkg/sort/#IntSlice>)[Float64Slice](<https://golang.google.cn/pkg/sort/#Float64Slice>)和 [StringSlice](<https://golang.google.cn/pkg/sort/#StringSlice>)也类似 。
